# 第5讲：求和（Sums）

求和对于递推、计数、概率、算法运行时间、大型系统性能、机器学习等领域都非常有用！

## 1.1 年金（Annuity）

中彩票赢得的 100 万通常是以年度分期支付的形式发放。设想每年 5 万，发放 20 年（或者每年 1 元，发放 100 万年）。它们的价值相同吗？**不一样！** 现在的钱比未来的钱更有价值！

设想现在得到 5 万和在 10 年后得到 5 万。如果现在拿到，我可以投资它，并积累 10 年的利息！10 年后它的价值会大得多。

所以，选择：每年 5 万，持续 20 年，还是现在一次性拿到 100 万？（绝对选 100 万！）那现在拿 70 万呢？50 万呢？

这正是**贷款**的运作方式：现在拿到一笔总金额，然后以分期付款方式偿还，并考虑利息。这被称为**年金（annuity）**。

让我们简化假设：固定利率为 $p$。因此今天 $1$ 元在 1 年后价值 $\$(1+p)$，2 年后价值 $\$(1+p)^2$，以此类推。反之，1 年后的 $\$1$ 相当于今天的 $1/(1+p)$。10 年后的 $\$1$ 相当于今天的 $(1/(1+p))^{10}$。

因此，设想一个 $n$ 年、每年 $\$m$ 的年金，利率为 $p$（例如 $p = 0.0533$，是美联储今天的利率）。

所以：现在有 $m$，1 年后有 $m$，2 年后有 $m$，...，$(n-1)$ 年后有 $m$。根据我们的假设，这相当于今天的一次性总额，其价值为：

$$V_1 = m + \frac{m}{1+p} + \frac{m}{(1+p)^2} + \cdots + \frac{m}{(1+p)^{n-1}} = \sum_{k=0}^{n-1} m \cdot \left(\frac{1}{1+p}\right)^k = m \cdot \sum_{k=0}^{n-1} x^k \quad \text{其中 } x = \frac{1}{1+p}$$

我们想要**闭式公式**（closed form）！（什么是闭式？基本上，就是可以直接输入计算器的公式，不含求和符号、省略号、递推等。）

## 1.2 扰动法（Perturbation Method）

**等比级数（Geometric Series）**：$\sum_{k=0}^{n-1} x^k = 1 + x + x^2 + \cdots + x^{n-1}$。我们已知闭式公式为 $\frac{1-x^n}{1-x}$。

我们在习题课 02 中已经用归纳法证明过了。一般来说，如果你知道（或能猜到！）答案，通常用归纳法证明是直接可行的。这被称为**猜测-验证法（Guess and Check method）**。困难的部分在于发现/猜测答案，而非证明它。

（在这种情况下，归纳步骤归结为证明 $(1-x^n)/(1-x) + x^n = (1-x^{n+1})/(1-x)$，可以通过代数验证。）

但是，如果我们事先不知道这个闭式，该如何**发现**它呢？

Gauss 曾用一个著名的方法（扰动法）解决了 $1+2+3+\cdots+n = n(n+1)/2$。

**扰动法**：将求和与自身或其修改版本进行比较，希望各项能够很好地合并。在这里，乘以 $x$ 会生成一个看起来非常相似的求和：

$$S = 1 + x + x^2 + x^3 + \cdots + x^{n-1}$$
$$xS = x + x^2 + x^3 + \cdots + x^{n-1} + x^n$$

$$S - xS = 1 - x^n$$，因为其余所有项都抵消了！所以 $(1-x)S = (1-x^n)$，因此 $S = \frac{1-x^n}{1-x}$。

回到年金问题：

$$V_1 = m \cdot \frac{1-x^n}{1-x} = m \cdot \frac{1 - \left(\frac{1}{1+p}\right)^n}{1 - \frac{1}{1+p}}$$

如果 $m = 50\text{k}$，$n = 20$，$p = 0.0533$，则 $V_1 \approx \$638,\!340$。

那么每年 $1$ 元、持续 100 万年的年金呢？事实上，让我们假设它永远持续下去。$\sum_{k=0}^{\infty} x^k$ 是多少？假设 $|x| < 1$，

$$\sum_{k=0}^{\infty} x^k = \lim_{n \to \infty} \sum_{k=0}^{n-1} x^k = \lim_{n \to \infty} \frac{1-x^n}{1-x} = \frac{1}{1-x}$$

$$V_2 = \frac{1}{1-x} = \frac{1}{1 - \frac{1}{p+1}} = \frac{p+1}{p}$$

相同利率下 $V_2 \approx \$19.76$。

每年付钱、永远持续的债券虽然反直觉地只有有限的总价值，但这就是利率在起作用。这类**永续债券（perpetual bonds）**很少见但确实存在！最早存世的一张是由一家荷兰水务公司在 1624 年发行的。已知今天有五张这样的债券存世。Yale 以 $24,000 的价格获得了一张，现在每年从中获得 €11.35 的收益。

## 1.3 有根据的猜测，即拟设法（Ansatz Method）

如何计算 $S := \sum_{k=1}^{n} k^2$ ？

**方法 1**：已经知道答案 $\frac{n(n+1)(2n+1)}{6}$。可以用归纳法证明！归纳步骤归结为证明：

$$\frac{n(n+1)(2n+1)}{6} + (n+1)^2 = \frac{(n+1)(n+2)(2n+3)}{6}$$

可以通过代数验证。

但如果我们不知道答案呢？做一个**部分猜测**，用未知变量表示未知数字，然后解出它们的值。在这个例子中，我们猜测它是一个三次多项式：

$$\sum_{k=1}^{n} k^2 = an^3 + bn^2 + cn + d$$

对某些常数 $a, b, c, d$ 成立。这意味着：

$$
\begin{aligned}
0a + 0b + 0c + d &= 0 \\
a + b + c + d &= 1^2 \\
8a + 4b + 2c + d &= 1^2 + 2^2 \\
27a + 9b + 3c + d &= 1^2 + 2^2 + 3^2
\end{aligned}
$$

这些信息足以求解：$a = 1/3$，$b = 1/2$，$c = 1/6$，$d = 0$。

那么我们能否得出 $\sum_{k=1}^{n} k^2 = \frac{1}{3}n^3 + \frac{1}{2}n^2 + \frac{1}{6}n$ 的结论？**还不行**；我们只知道这对 $n \in \{0, 1, 2, 3\}$ 为真。怎样才能检验它对所有 $n$ 是否为真？**归纳法！** 如果归纳过程顺利，我们就有了一个证明，证明我们的公式是正确的！否则，归纳将失败，我们就会知道猜测是错的。

已经检查了 $n \in \{0, 1, 2, 3\}$。归纳步骤可以通过代数验证。

注意：求和 $\sum_{n=1}^{0} f(n)$ 被称为**空求和（empty summation）**，其值为 0。

## 1.4 双重求和（Double Sums）

有时我们需要计算「求和的求和」，即**双重求和**。例如：

$$\sum_{i=1}^{n} \sum_{j=1}^{i} j$$

要计算这样一个求和，首先找到内层求和的闭式，然后用它来找到外层求和的闭式。

$$
\begin{aligned}
\sum_{i=1}^{n} \sum_{j=1}^{i} j &= \sum_{i=1}^{n} \frac{i(i+1)}{2} \\
&= \sum_{i=1}^{n} \left(\frac{1}{2}i^2 + \frac{1}{2}i\right) \\
&= \frac{1}{2}\sum_{i=1}^{n} i^2 + \frac{1}{2}\sum_{i=1}^{n} i \\
&= \frac{n(n+1)(2n+1) + 3n(n+1)}{12} \\
&= \frac{n(n+1)(n+2)}{6}
\end{aligned}
$$

假设我们要计算 $\sum_{i=1}^{n} \sum_{j=i}^{n} j$。对于双重求和，一个常用的有用工具是**交换求和顺序**。总的来说，我们是在对满足 $1 \leq i \leq n$ 和 $i \leq j \leq n$（即 $1 \leq i \leq j \leq n$）的所有对 $(i, j)$ 求和。关键观察是，我们也可以将其表达为 $1 \leq j \leq n$ 且 $1 \leq i \leq j$。

$$
\begin{aligned}
\sum_{i=1}^{n} \sum_{j=i}^{n} j &= \sum_{j=1}^{n} \sum_{i=1}^{j} j \\
&= \sum_{j=1}^{n} j^2 \\
&= \frac{n(n+1)(2n+1)}{6}
\end{aligned}
$$

那么 $\sum_{j=1}^{n} j2^j$ 呢？处理它的一种（可能反直觉的）方法是，通过表达 $j = \sum_{i=1}^{j} 1$ 来引入双重求和，然后交换求和顺序。

$$
\begin{aligned}
\sum_{j=1}^{n} j2^j &= \sum_{j=1}^{n} \sum_{i=1}^{j} 2^j \\
&= \sum_{i=1}^{n} \sum_{j=i}^{n} 2^j \\
&= \sum_{i=1}^{n} \left(2^{n+1} - 2^i\right) \\
&= n2^{n+1} - \sum_{i=1}^{n} 2^i \\
&= n2^{n+1} - 2^{n+1} + 2 \\
&= (n-1)2^{n+1} + 2
\end{aligned}
$$

## 1.5 近似求和：积分法（The Integral Method）

$\sum_{k=1}^{n} \sqrt{k}$ 呢？**没有已知的闭式！** 我们能做的最好就是近似。

假设 $f(x)$ 是 $x$ 的弱递增函数，且 $S = \sum_{k=1}^{n} f(k)$。（对于上面的例子，$f(x) = \sqrt{x}$。）回忆积分学中的 Riemann 和：我们如何近似 $I := \int_1^n f(x) \, dx$ ？

如果我们用 $f(\lfloor x \rfloor)$ 低估 $f(x)$，就可以得到 $I$ 的下界：

$$I = \int_1^n f(x) \, dx \geq \int_1^n f(\lfloor x \rfloor) \, dx = \sum_{k=1}^{n-1} \int_k^{k+1} f(\lfloor x \rfloor) \, dx = \sum_{k=1}^{n-1} f(k)$$

等价地，这用 $I$ 给出了 $S$ 的上界：

$$S = \sum_{k=1}^{n} f(k) = f(n) + \sum_{k=1}^{n-1} f(k) \leq f(n) + I$$

类似地，我们可以用 $f(\lceil x \rceil)$ 高估 $f(x)$ 来得到：

$$I \leq \int_1^n f(\lceil x \rceil) \, dx = \sum_{k=2}^{n} f(k)$$

等价地，这用 $I$ 给出了 $S$ 的下界：

$$S = f(1) + \sum_{k=2}^{n} f(k) \geq f(1) + I$$

**定理 1（递增函数的积分界限，Integral Bound - Increasing）**：如果 $f: [1, n] \to \mathbb{R}$ 是弱递增的，则

$$f(1) + \int_1^n f(x) \, dx \leq \sum_{k=1}^{n} f(k) \leq f(n) + \int_1^n f(x) \, dx$$

对于 $f(x) = \sqrt{x}$，我们有 $\int_1^n \sqrt{x} \, dx = \left[\frac{2}{3} x^{3/2}\right]_1^n = \frac{2}{3}n^{3/2} - \frac{2}{3}$，所以

$$1 + \frac{2}{3}n^{3/2} - \frac{2}{3} \leq S \leq \sqrt{n} + \frac{2}{3}n^{3/2} - \frac{2}{3}$$

因此 $S$ 略大于 $\frac{2}{3} n^{3/2}$。

相同的方法可以证明：

**定理 2（递减函数的积分界限，Integral Bound - Decreasing）**：如果 $f: [1, n] \to \mathbb{R}$ 是弱递减的，则

$$f(n) + \int_1^n f(x) \, dx \leq \sum_{k=1}^{n} f(k) \leq f(1) + \int_1^n f(x) \, dx$$

**定理 3（反常积分的积分界限，Integral Bound - Improper）**：如果 $f: [1, \infty) \to \mathbb{R}$ 是弱递减的，则级数 $\sum_{k=1}^{\infty} f(k)$ 收敛当且仅当反常积分 $\int_1^\infty f(x) \, dx$ 收敛。如果它们收敛，则

$$\int_1^\infty f(x) \, dx \leq \sum_{k=1}^{\infty} f(k) \leq f(1) + \int_1^\infty f(x) \, dx$$

**例**：假设 $f(x) = x^{-2}$。定义：

$$S := \sum_{k=1}^{\infty} k^{-2}, \quad I := \int_1^\infty x^{-2} \, dx = \lim_{n\to\infty} \big[{-x^{-1}}\big]_1^n = 1$$

定理 3 给出界限 $S \in [I, I + f(1)] = [1, 2]$，这不是很精确的近似。如何改进近似？

**想法**：近似 $S$ 的尾部，例如：

$$S' := \sum_{k=4}^{\infty} x^{-2}, \quad I' := \int_4^\infty x^{-2} \, dx = \frac{1}{4}$$

现在 $S' \in [I', I' + f(4)] = \left[\frac{1}{4}, \frac{5}{16}\right]$，所以 $S = f(1) + f(2) + f(3) + S' \in \left[\frac{232}{144}, \frac{241}{144}\right]$。这比之前的近似精确得多！

**选读材料，不考**：$S = \frac{\pi^2}{6}$。证明略（需用到复分析和多项式根的性质）。
